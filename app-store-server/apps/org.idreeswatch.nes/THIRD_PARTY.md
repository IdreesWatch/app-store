# Third-party source

This application uses the Nofrendo core maintained by
[retro-go](https://github.com/ducalex/retro-go), pinned from commit
`4ced120669750ca7228fd0414211430c1d923166`.

The vendored core retains its copyright notices, `COPYING`, and `CREDITS`
files. The bundled `COPYING` file is GPL-2.0-only, so this reference package
is published under GPL-2.0-only. IdreesWatch-specific module
integration is kept outside the vendored directory.

No Nintendo ROM, BIOS, artwork, trademark, or game content is included.
Users must supply legally obtained `.nes` files on their own SD card.
